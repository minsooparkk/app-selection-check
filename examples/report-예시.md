## 확실한 것 (3)

### 가나메일 — 1 유지(API·MCP)
- 드나드는 자료: 고객과 주고받는 메일
- 할 일: API · MCP 로 스크립트 수집
- 참고: API 이용 조건: 무료 계정 가능
- 근거: https://docs.example.com/ganamail/api , https://docs.example.com/ganamail/mcp (확인 2026-01-15)

### 국민톡 — 2 유지(대형 플랫폼)
- 드나드는 자료: 고객·거래처와의 대화
- 할 일: 하루 한 번 내보내 정리: 데스크톱 앱의 대화 내보내기를 하루 한 번 실행한 뒤 LLM 으로 정리
- 참고: API 는 있으나 내 자료를 읽는 용도가 아님(보내기 전용) → 없는 것으로 봄
- 근거: https://docs.example.com/ktalk/message-api (확인 2026-01-15)

### 통화 녹음 — 3 유지(로컬 정형화)
- 드나드는 자료: 고객 통화
- 할 일: 녹음 파일을 폴더 동기화로 PC 에 모아 로컬 받아쓰기 → LLM 으로 화자 분리·정리


## 불확실한 것 — 다시 확인 (2)

### 카타장부 — 미정
- 드나드는 자료: 전표·장부
- 할 일: API·MCP 유무(또는 내 자료를 읽을 수 있는지)를 다시 확인
- 비어 있는 근거: API 가 있다고 적었지만 공식 문서 주소가 없음

### 파하일정 — 미정
- 드나드는 자료: 일정
- 할 일: API·MCP 유무(또는 내 자료를 읽을 수 있는지)를 다시 확인
- 비어 있는 근거: API 가 있다고 적었지만 공식 문서 주소가 없음
- 비어 있는 근거: 확인한 날짜가 없음(없다는 결론은 언제 확인했는지가 근거)


## 판단이 필요한 것 — 사용자가 정함 (3)

### 다라메신저 — 1 유지(API·MCP)
- 드나드는 자료: 팀 대화
- 할 일: MCP(공식 여부 아님) 로 스크립트 수집
- 정할 것: 공식이 아닌 MCP 하나에만 기댄다. 만든 곳·갱신 주기·권한 범위를 보고 쓸지 정한다
- 근거: https://github.com/example/dara-mcp (확인 2026-01-15)

### 마바노트 — 교체
- 드나드는 자료: 회의 녹음과 회의록
- 할 일: 대안: 사아노트
- 정할 것: 대안으로 옮길지와 시기(자료 이전, 상대방 안내)

### 자차포털 — 포기 검토
- 드나드는 자료: 기관 제출·조회
- 할 일: 바꿀 수 없고 꺼낼 길도 없다. 이 채널은 연결하지 않고 필요한 것만 손으로 옮긴다
- 정할 것: 이 채널 없이 업무가 되는가. 안 되면 손으로 옮길 최소 범위를 정한다
